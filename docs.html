C#, pero hablado nya~

NyanSharp es un lenguaje compilado que se escribe con las palabras de una loli kawaii de anime y produce un ejecutable nativo de .NET. Toda la potencia de C#; ninguna de sus palabras clave.

compilado · .NET 8extensión .nyaVS Code
// hola.nya
onegai sekai nya

oshiro Hola
{
    minna nakama Programa
    {
        minna zutto nanimo hajimeru()
        {
            iu("Konnichiwa, sekai~! (◕‿◕✿)") nya
        }
    }
}

Qué es NyanSharp

Un dialecto de C# con vocabulario propio. El compilador nyac traduce el archivo .nya a C# real y llama a .NET para generar un binario. Por eso funciona todo lo que funciona en C# 12: genéricos, LINQ, async, pattern matching, records, tuplas, la librería estándar completa y cualquier paquete NuGet que añadas.

Idea clave. Solo cambian las palabras clave y el punto y coma. Los nombres de tipos del framework (List, Console, Exception…), los operadores y la sintaxis siguen siendo los de C#.

Instalación

Necesitas .NET SDK 8 y Python 3. En este equipo ya está todo colocado:

~/nyansharp/nyac

El compilador. Un solo archivo Python.

~/bin/nyac

Enlace en el PATH. Escribe nyac desde cualquier carpeta.

~/.vscode/extensions/nexvylia.nyansharp-0.1.0

Extensión de VS Code: colores y snippets.

Para llevarlo a otra máquina: copia la carpeta ~/nyansharp, instala .NET 8 y crea el enlace:

ln -s ~/nyansharp/nyac ~/bin/nyac
cp -r ~/nyansharp/vscode-ext ~/.vscode/extensions/nexvylia.nyansharp-0.1.0

Compilar y ejecutar

nyac archivo.nya

Compila. El ejecutable queda en ./bin/archivo junto al fuente.

nyac run archivo.nya

Compila y ejecuta en el acto.

nyac cs archivo.nya

Muestra el C# generado sin compilar. Útil para depurar.

nyac diccionario

Lista las 101 palabras. Admite filtro: nyac diccionario for.

La primera compilación tarda unos segundos porque .NET restaura el proyecto. Las siguientes van en torno a un segundo. Los ficheros intermedios viven en .nyabuild/, que puedes borrar sin miedo.

Uso en VS Code

Abre cualquier archivo .nya y tendrás resaltado de sintaxis. Si no aparece, reinicia VS Code una vez tras la instalación.

Atajos

Con la carpeta ~/nyansharp abierta (trae .vscode/tasks.json):

Ctrl + Shift + B

Compila el archivo activo. Los errores aparecen en la pestaña Problemas con enlace a la línea.

Terminal → Ejecutar tarea de prueba

Compila y ejecuta en el terminal integrado.

Snippets

Escribe el prefijo y pulsa Tab: programa (esqueleto completo), nakama (clase), moshi (if), kurikaeshi (for), hitotsuzutsu (foreach), ganbaru (try/catch).

Para usar las tareas en otro proyecto, copia ~/nyansharp/.vscode/tasks.json a su carpeta .vscode/.

Proyectos y paquetes NuGet

Un archivo suelto vale para empezar. Para programas de verdad, crea un proyecto: una carpeta con varios .nya y un nyansharp.json.

nyac new miapp

Crea miapp/ con nyansharp.json, main.nya y .gitignore.

nyac build

Compila todos los .nya de la carpeta (y subcarpetas) en un solo ejecutable.

nyac run -- arg1 arg2

Compila y ejecuta pasando argumentos a hajimeru(kotoba[] args).

nyac add Newtonsoft.Json

Añade un paquete NuGet. Busca la última versión, o pásala: nyac add Dapper 2.1.35.

// nyansharp.json
{
  "nombre": "miapp",
  "tipo": "exe",            // "exe" o "lib" (genera una .dll)
  "paquetes": { "Newtonsoft.Json": "13.0.3" },
  "nullable": iie
}
Ejemplo completo. ~/nyansharp/ejemplos/biblioteca: dos archivos, records, eventos, yield, with, pattern matching con when y serialización JSON con Newtonsoft. Ejecútalo con nyac run ejemplos/biblioteca.

Cobertura de C#

Las 101 palabras cubren todas las palabras clave de C# 12, incluidas record, yield, lock, params, delegate, event, operator, implicit/explicit, unsafe, stackalloc y los tipos sin signo. Todo lo que no es palabra clave (LINQ, Task, List, atributos, NuGet) se usa tal cual.

nyac check

Avisa si has llamado a una variable con una palabra reservada de C# (por ejemplo kazu int = 3). Solución: renómbrala o escríbela como @int.

Reglas del lenguaje

1. El punto y coma es nya

NyanSharp
kazu edad = 14 nya
iu(edad) nya
C# generado
int edad = 14;
Console.WriteLine(edad);

Dentro de un for se admite el ; normal para separar las tres partes. También puedes escribir ; en cualquier sitio si tienes prisa: el compilador lo acepta.

2. Las virgulillas ~ son decoración

Cualquier ~ fuera de una cadena o comentario se ignora. Sirve para dar entonación: kaeru 0 nya~. Dentro de comillas se conserva tal cual.

3. Cadenas y comentarios no se traducen

El compilador nunca toca el texto de "…", 'x' ni de los comentarios. Puedes escribir «nya» o «desu» en un texto sin que pase nada. La única excepción son los huecos {…} de las cadenas interpoladas $"…": ahí sí se traduce, para que $"{kazu.MaxValue}" funcione.

4. Los identificadores propios son libres

Cualquier palabra que no esté en el diccionario pasa intacta: nombres de variables, clases, métodos y todo el framework de .NET. Si necesitas un nombre que coincide con una palabra clave, antepón @: kotoba @kazu = "x" nya.

5. Entrada y salida

Mensajes de error

Los errores del compilador de C# se muestran con la línea y columna del archivo .nya, porque la traducción conserva las líneas una a una. El código (CS0029, CS0103…) es el oficial de Microsoft: puedes buscarlo tal cual.

Cómo funciona por dentro

El compilador tiene tres pasos:

1 · tokenizar

Una expresión regular separa comentarios, cadenas, caracteres, palabras y símbolos. Así las cadenas quedan protegidas.

2 · traducir

Cada palabra se busca en el diccionario. Si existe, se sustituye; si no, pasa intacta. ~ se elimina.

3 · dotnet build

Se genera un .csproj mínimo en .nyabuild/ y .NET compila en Release a bin/.

Para añadir una palabra nueva, edita el diccionario PALABRAS al principio de ~/nyansharp/nyac y, si quieres color en VS Code, añádela también a vscode-ext/syntaxes/nya.tmLanguage.json.

Preguntas frecuentes

¿Es realmente compilado?
Sí. El resultado es un ejecutable ELF nativo más su DLL de .NET, igual que cualquier programa C# compilado con dotnet build.
¿Puedo usar paquetes NuGet?
Sí: nyac add Paquete dentro de un proyecto.
¿Qué licencia tiene?
MIT. Puedes usarlo, modificarlo y distribuirlo libremente, también en proyectos comerciales.
¿Puedo mezclar palabras C# y NyanSharp?
Sí. int, if o ; siguen funcionando porque el compilador solo sustituye lo que está en el diccionario. Pero pierde gracia.
¿Varios archivos en un proyecto?
Sí: nyac new y todos los .nya de la carpeta se compilan juntos. Ver «Proyectos y NuGet».
¿Funciona en Windows o Mac?
Sí, con .NET 8 y Python 3 instalados. El ejecutable se genera para el sistema donde compilas.

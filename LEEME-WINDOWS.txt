NyanSharp para Windows
======================
1. Instala Python 3 (marca "Add to PATH")  https://www.python.org/downloads/
2. Instala .NET SDK 8                       https://dotnet.microsoft.com/download/dotnet/8.0
3. Instala VS Code                          https://code.visualstudio.com/
4. Doble clic en instalar.bat
5. Abre una terminal nueva:  nyac run ejemplos\hola.nya

Documentación: docs.html
Extensión VS Code (si el .bat no la instaló): VS Code > Extensiones > "..." > Instalar desde VSIX > nyansharp-1.0.0.vsix
